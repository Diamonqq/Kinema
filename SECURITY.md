# Security and privacy

Kinema is a local, single-user application. Keep it bound to localhost. Do not
publish the server to the internet or share one data directory across users.

Never post API keys, CLI credential files, chats, homework uploads or the contents
of your data directory in an issue. A screenshot should hide account details.

For a suspected security vulnerability, use this repository's **Security → Report
a vulnerability** when available. Do not publish exploit details or credentials
in a public issue. Ordinary bugs belong in the issue tracker.
